## Chronological

**By publication date:** [CPD](#cpd) | [Remote](#remote) | [Node](#node) | [Archive](#archive)

Newest publications appear first. Dates use the original GitHub publication timestamp in **Europe/Prague**, not the application build, file replacement or last edit time. An archived revision may have been published here later than its revision date.

CPD hotfix numbers (`h1`, `h2`, ...) restart for each application version and increase from the oldest publication to the newest. They are display labels only; update tags, filenames and version identifiers are unchanged.
